## 📋 Sobre o Projeto

**🏦 Cenário Fictício: Sistema para o Banco TechBank**

**1. Descrição da Empresa**

O **TechBank** é um banco digital em rápida expansão que oferece serviços de conta corrente, poupança, cartões de crédito e investimentos para clientes em todo o país. Diferente dos bancos tradicionais, o TechBank não possui agências físicas; todo o atendimento e operações são realizados por meio de um aplicativo móvel e uma plataforma web.

**2. O Problema / Necessidade de Informatização**

Atualmente, o TechBank gerencia suas operações utilizando microsserviços legados que guardam dados de forma descentralizada. Isso tem gerado inconsistências graves, como clientes que atualizam o endereço no cadastro de cartões, mas o endereço antigo continua na conta corrente. Além disso, o banco não consegue rastrear com precisão qual funcionário (gerente de contas) é responsável pelo atendimento de qual cliente, e há lentidão para calcular o saldo consolidado dos investimentos em tempo real.

Para resolver isso, o TechBank precisa de um **novo modelo de banco de dados centralizado e relacional** capaz de unificar o cadastro de clientes, contas, cartões, funcionários e transações, garantindo a integridade dos dados e o suporte à conformidade regulatória do Banco Central.
